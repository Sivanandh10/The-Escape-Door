## 1. Next.js 16.4: what changed vs 14/15

### 1.1 Breaking changes that will bite you [docs: upgrading/version-16.md]
- **Request APIs are async only.** Sync access was removed in 16. `await cookies()`, `await headers()`, `await draftMode()`, `await params`, `await searchParams`. The `params`/`id` props of `opengraph-image`, `twitter-image`, `icon` and `apple-icon` are Promises too. In `sitemap({ id })`, `id` is also a Promise.
- **Typed helpers are global** (generated by `next dev`/`next build`/`npx next typegen`): `PageProps<'/shop/[slug]'>`, `LayoutProps<'/'>`, `RouteContext<'/api/x/[id]'>`. The scaffold's `layout.tsx` already uses `LayoutProps<'/'>`.
- **`middleware.ts` → `proxy.ts`** (`export function proxy(request)`). Proxy always runs on the **Node.js runtime**, and you cannot configure that. `skipMiddlewareUrlNormalize` became `skipProxyUrlNormalize`. With `src/`, the file is `src/proxy.ts`.
- **Turbopack is the default** for `dev` and `build`. Do not add a `webpack()` config: `next build` fails if one exists. `turbopack` is a top-level key.
- **`next lint` was removed.** Use `eslint` (already in scripts). `next build` no longer lints.
- **`revalidateTag(tag)` needs a 2nd arg**: `revalidateTag('products', 'max')`. In Server Actions, use the new **`updateTag(tag)`** for read-your-writes. Use `refresh()` from `next/cache` to refresh the client router from an action.
- **next/image defaults changed:**
  - `qualities` is now `[75]`. Any other `quality` is coerced, and direct `/_next/image?q=` requests with other values return 400.
  - `minimumCacheTTL` is 4 h.
  - 16 is gone from `imageSizes`.
  - `maximumRedirects` is 3.
  - Local `src` values with a query string need `images.localPatterns[].search`.
  - `images.domains` is deprecated: use `remotePatterns`.
- **Scroll behaviour:** Next no longer overrides `scroll-behavior: smooth` during navigation. Do not set CSS smooth scroll anyway, because Lenis owns scrolling.
- **Parallel-route slots need `default.tsx`**, or the build fails.
- AMP, `serverRuntimeConfig`/`publicRuntimeConfig`, `experimental.ppr`, `experimental.dynamicIO` and `unstable_rootParams` were removed. Use env vars, with `NEXT_PUBLIC_` for the client.

### 1.2 Cache Components is ON: the rendering model is different [docs: config/cacheComponents.md, getting-started/08-caching.md, guides/migrating-to-cache-components.md]
- **Data is dynamic by default.** You opt in to caching with `'use cache'` plus `cacheLife()`/`cacheTag()`, all from `next/cache` (stable, no `unstable_`). Next prerenders a **static shell** and streams the dynamic parts (this is PPR).
- **Any uncached async work, or any read of `cookies()`/`headers()`/`searchParams`/unknown `params`, must sit inside `<Suspense>`.** Otherwise the dev overlay shows a "blocking-route" insight, and the build or prerender errors.
- **Route segment configs you must NOT use:**
  - `export const dynamic`: remove it.
  - `export const revalidate`: replace it with `cacheLife`.
  - `export const fetchCache`.
  - **`export const dynamicParams`**: the build fails. Call `notFound()` instead.
  - **`export const runtime`**: any value, including `'nodejs'`. It is not supported.
- **`Math.random()`, `Date.now()`, `new Date()` and `crypto.randomUUID()` during render** need either `await connection()` (from `next/server`) inside `<Suspense>`, or a `'use cache'` scope. `performance.now()` is exempt.
- **A `'use cache'` function cannot call `cookies()`/`headers()`/`searchParams`**, including transitively, through a helper that does. Read the value outside and pass it in as an argument. So **never** use the cookie-based Supabase server client inside `'use cache'`, `generateStaticParams` or `generateMetadata`. Use a cookie-less client (§7.2).
- `'use cache'` entries live **in memory per instance**. In serverless they are mostly rebuilt per instance at runtime, while build-time entries are fine. The Netlify adapter source has a `use cache` handler (`configureUseCacheHandlers`) [src], but **whether entries persist across Netlify function instances is UNVERIFIED.**
- **`unstable_cache` and the `fetch` cache still work** and survive across deploys.
- **`<Activity>` navigation:** when you navigate away, the previous route stays in the DOM with `display:none` instead of unmounting. Next keeps a few of them.
  - Effects **do** run their cleanup when a route is hidden and re-run when it is shown again.
  - **Consequences for us:**
    1. Every GSAP/ScrollTrigger/Lenis/R3F/IntersectionObserver setup must clean up properly. `useGSAP` does this.
    2. A hero `<video>` keeps playing while hidden unless you pause it in a `useLayoutEffect` cleanup.
    3. Page-level `<style>` and CSS variables leak into the visible page. Toggle `style.media = 'not all'` in a callback ref cleanup.
    4. Call `ScrollTrigger.refresh()` when a page is shown again.
    5. Check in DevTools that WebGL contexts do not pile up after navigating between pages (**UNVERIFIED** whether R3F fully disposes the renderer on an Activity hide).
- **`partialPrefetching: true`:** links prefetch one reusable App Shell per route. `<Link prefetch={true}>` also prefetches the params data.
- `export const instant = true | false` (a segment config) controls dev-time instant-navigation validation. Use `instant = false` on `/admin` layouts, which legitimately block on the session.

```tsx
// Static + cached + streamed on one page [docs pattern]
import { Suspense } from 'react'
import { cacheLife, cacheTag } from 'next/cache'

async function Catalogue() {
  'use cache'
  cacheLife('hours')
  cacheTag('products')
  const products = await getProducts()          // cookie-less read
  return <Grid products={products} />
}
export default function Page() {
  return (<>
    <Hero />                                     {/* static, in the shell */}
    <Catalogue />                                {/* cached, in the shell */}
    <Suspense fallback={<CartSkeleton />}><CartFromCookie /></Suspense>  {/* runtime */}
  </>)
}
```

### 1.3 `[slug]` pages with generateStaticParams [docs: generate-static-params.md, dynamic-routes.md, ISR-with-cache-components.md]
- With Cache Components, `generateStaticParams` **must return at least one param**. An empty array is a build error. Params you did not list render on demand and are then stored in the ISR cache. With `partialPrefetching`, the App Shell is served immediately.
- The build only validates the code paths that the sample params execute. A branch that reads `cookies()` for an unlisted slug fails **at runtime** unless it is inside `<Suspense>`.
- **In layouts**, pass the `params` promise down instead of awaiting it at the top. Otherwise the layout cannot be prerendered.

```tsx
// src/app/shop/[slug]/page.tsx
import { notFound } from 'next/navigation'
import { cacheLife } from 'next/cache'

export async function generateStaticParams() {
  return products.map((p) => ({ slug: p.slug }))      // ≥1 entry, from seed.ts
}
async function getProduct(slug: string) {
  'use cache'
  cacheLife('days')
  return products.find((p) => p.slug === slug) ?? null
}
export async function generateMetadata({ params }: PageProps<'/shop/[slug]'>): Promise<Metadata> {
  const p = await getProduct((await params).slug)
  if (!p) return {}
  return { title: p.name, description: p.blurb, alternates: { canonical: `/shop/${p.slug}` } }
}
export default async function Page({ params }: PageProps<'/shop/[slug]'>) {
  const p = await getProduct((await params).slug)
  if (!p) notFound()                                   // replaces dynamicParams=false
  return <ProductView product={p} />
}
```
- `generateMetadata` follows the same rules as the page. If it reads uncached data while the page is otherwise fully static, you get an explicit error. Fix it by using `'use cache'` in the data function, as above.

### 1.4 Fonts: next/font/google [docs: font.md; src: next/dist/compiled/@next/font]
- `subsets` is required whenever `preload` is true (the default). Values are validated against `font-data.json`, and an unknown subset is a build error.
- **Noto Sans JP's only subsets are `cyrillic, latin, latin-ext, vietnamese`. There is no `japanese` subset.** The Japanese glyphs come as ~100 numbered `unicode-range` slices. The loader downloads and self-hosts **every** file in Google's CSS, and preloads only the listed subsets [src: loader.js `findFontFilesInCss`]. The browser then fetches only the slices whose ranges your text actually uses. Rules:
  - Use `preload: false` and 1–2 weights only (each weight multiplies the slice count).
  - Use it only for short JP subtitles, never body copy.
  - Smallest option: subset the exact JP strings into one woff2 with `pyftsubset` (free) and load it with `next/font/local`.
- These fonts exist in next/font's list [runtime check of font-data.json]:
  - **Condensed caps:** Anton (400), Bebas Neue (400), Oswald (variable 200–700), League Gothic (variable, `wdth` axis), Antonio (variable 100–700), Saira Extra Condensed, Barlow Condensed, Teko (variable).
  - **JP display:** Dela Gothic One, Reggae One, Mochiy Pop One, Zen Kaku Gothic New, M PLUS 1p (JP glyphs via slices, same rule as above).
  - "Big Shoulders Display" is **not** in this version's list.
- Do not use Geist alone (playbook rule). Replace the scaffold fonts.

```tsx
// src/app/layout.tsx
import { Anton, Noto_Sans_JP } from 'next/font/google'
const anton = Anton({ weight: '400', subsets: ['latin'], variable: '--font-anton', display: 'swap' })
const jp = Noto_Sans_JP({ weight: ['400', '700'], subsets: ['latin'], preload: false, variable: '--font-jp', display: 'swap' })
// <html lang="en" className={`${anton.variable} ${jp.variable}`}>   [types]
```

### 1.5 Metadata, sitemap, robots, OG images, JSON-LD [docs + types]
- `export const metadata` / `generateMetadata` in Server Components only. Set `metadataBase: new URL(process.env.NEXT_PUBLIC_SITE_URL!)` in the root layout so OG URLs come out absolute. `themeColor`/`viewport` go in `export const viewport` / `generateViewport`, not in metadata.
- `src/app/sitemap.ts` → `MetadataRoute.Sitemap`. Entries accept `images: string[]` and `alternates`. It is a special route handler, cached unless it uses request-time APIs. **Avoid `new Date()` in it** under Cache Components: use fixed `lastModified` dates from your data.
- `src/app/robots.ts` → `MetadataRoute.Robots`.

```ts
export default function robots(): MetadataRoute.Robots {
  return { rules: [{ userAgent: '*', allow: '/', disallow: ['/admin', '/api/'] }], sitemap: `${SITE}/sitemap.xml` }
}
```
- **`opengraph-image.tsx`:** `import { ImageResponse } from 'next/og'`. Export `alt`, `size = { width: 1200, height: 630 }` and `contentType = 'image/png'`. `params` is a Promise.
  - **Limits:** flexbox and a CSS subset only (**no `display:grid`**). **500 KB bundle cap**, including fonts. **Fonts must be ttf/otf/woff, not woff2.**
  - Read fonts once at module scope: `const f = await readFile(join(process.cwd(), 'assets/og/Anton-Regular.ttf'))`.
  - Full Noto Sans JP TTF files are multiple MB, so they break the cap. Use a subset TTF of the JP strings, or no JP in OG images.
- JSON-LD: render `<script type="application/ld+json" dangerouslySetInnerHTML={{ __html: JSON.stringify(data).replace(/</g, '\\u003c') }} />` in the page or layout [docs: guides/json-ld.md].

### 1.6 next/image with Supabase Storage [docs + types]
```ts
// next.config.ts: keep the existing cacheComponents/partialPrefetching/turbopack keys
images: {
  remotePatterns: [new URL(`https://${process.env.NEXT_PUBLIC_SUPABASE_HOST}/storage/v1/object/public/**`)],
  formats: ['image/avif', 'image/webp'],
  qualities: [60, 75],            // every quality you pass must be listed (16.x default is [75])
},
```
- Use a literal host string if the env var is not available at config load. Signed URLs (`/storage/v1/object/sign/...?token=`) carry a query string. Do not send them through next/image; render them with `unoptimized` or a plain `<img>`, and only in the admin.
- On Netlify, next/image goes through **Netlify Image CDN**, and that counts as Netlify bandwidth (§8.4).
- Whether the adapter maps `remotePatterns` to Netlify's remote-image allowlist automatically is **UNVERIFIED**. If remote images 404 on a deploy preview, add `[images] remote_images = ["https://<ref>\\.supabase\\.co/.*"]` to netlify.toml.
- Supabase **Image Transformations are Pro-only** [c7: billing table]. Pre-compress product images to AVIF/WebP yourself (sharp/squoosh, free) and let next/image resize them.

### 1.7 Route handlers [docs: 15-route-handlers.md, route.md]
- `GET` handlers follow the page prerender model. They are **prerendered at build** unless they read `request` (url/headers/body), cookies, headers, network or DB, or call `Math.random()`/`connection()`. POST is always dynamic.
- Signature: `export async function POST(request: Request, ctx: RouteContext<'/api/x/[id]'>)`. `ctx.params` is a Promise.
- **No `export const runtime`** (Cache Components).
- Rate limiting in serverless: in-memory counters do not work across instances. Use the honeypot, zod and a Supabase-side throttle keyed by a **hashed** IP + day (never store raw IPs), or move the endpoint to a Netlify Function, which has native `config.rateLimit` (§8.2).

### 1.8 Server Actions [docs: 07-mutating-data.md, server-actions.md]
- `'use server'` at the top of the file or function. Pending UI: `const [state, action, pending] = useActionState(fn, initial)`.
- Re-verify auth **inside every action**, because UI checks are not authorization. Call `updateTag('products')` after admin writes.
- Cookies can only be **set** in Server Actions or Route Handlers, never during render.

### 1.9 Client-only components and lazy loading [docs: guides/lazy-loading.md]
- `dynamic(() => import(...), { ssr: false })` is **only allowed inside a `'use client'` file**. In a Server Component it errors.

```tsx
'use client'
import dynamic from 'next/dynamic'
const DoorScene = dynamic(() => import('@/components/three/DoorScene'), { ssr: false, loading: () => null })  // [types]
```

### 1.10 proxy.ts: keep it tiny [docs: proxy.md]
- With no `matcher`, it runs on **every** request, including `_next/static` and images. On Netlify it runs as an Edge Function, and every invocation is a metered web request.
- **Match only `/admin/:path*` and `/auth/:path*`.** Public catalogue pages must not touch the session, or they lose static caching.

## 2. Tailwind v4.3 [runtime: compiled with @tailwindcss/node 4.3.3]
- No `tailwind.config.*`. Everything lives in CSS: `@import "tailwindcss";`, then `@theme { ... }`. Each `--color-*`, `--font-*`, `--text-*`, `--animate-*` and `--breakpoint-*` token generates its utilities. Opacity modifiers work on tokens: `bg-volt/40` compiles to a `color-mix()`.
- **Reference next/font variables through `@theme inline`**, so the utility inlines the var (the scaffold already does this).
- Custom utilities use `@utility name { ... }`. Custom variants use `@custom-variant name (...)`.
- Arbitrary values:
  - `w-[min(90vw,72rem)]`.
  - Arbitrary property: `[writing-mode:vertical-rl]`.
  - **CSS-var shorthand is now parentheses: `bg-(--color-lilac)`.** The v3 form `bg-[--x]` is wrong in v4.
- Built-in `motion-reduce:` / `motion-safe:` variants exist.
- **GSAP conflict:** v4 `rotate-*`, `translate-*` and `scale-*` compile to the **individual CSS properties** (`rotate:`, `translate:`, `scale:`), not `transform:` [runtime: `-rotate-90` → `rotate: calc(90deg * -1)`]. GSAP's `x/y/rotation/scale` write `transform`, so the two **stack**. Never put Tailwind transform utilities on elements GSAP animates. Use a wrapper element.

```css
@import "tailwindcss";
@theme inline {
  --font-display: var(--font-anton), "Arial Narrow", sans-serif;
  --font-jp: var(--font-jp), sans-serif;
}
@theme {
  --color-ink: #0b0b0c; --color-volt: #f5e663; --color-lilac: #c9b6ff;
  --text-mega: clamp(4rem, 12vw, 14rem);
  --animate-ticker: ticker 30s linear infinite;
  @keyframes ticker { to { transform: translateX(-50%); } }
}
@utility screentone { background-image: radial-gradient(currentColor 1px, transparent 1.2px); background-size: 6px 6px; }
```
(Token values above are placeholders for syntax only. The real palette is DESIGN.md's job.)

## 3. GSAP 3.15, @gsap/react, Lenis 1.3.27

### 3.1 GSAP imports [src: package files + README; types]
- **Every plugin is free, including commercial use**: SplitText, MorphSVG, DrawSVG, ScrollSmoother, Inertia, ScrambleText, Physics2D, CustomBounce/Wiggle, GSDevTools and the rest. It all ships in the public `gsap` package under the "Standard 'no charge' license" [README: "100% FREE … even for commercial use"]. No Club token or registry is needed.
- Import paths (case-sensitive, named or default export):

```ts
import gsap from 'gsap'
import { ScrollTrigger } from 'gsap/ScrollTrigger'
import { SplitText } from 'gsap/SplitText'
import { DrawSVGPlugin } from 'gsap/DrawSVGPlugin'
import { MorphSVGPlugin } from 'gsap/MorphSVGPlugin'
import { Flip } from 'gsap/Flip'

import { useGSAP } from '@gsap/react'            // after: npm i @gsap/react

```
- Register plugins in a `'use client'` module. GSAP touches `window` and must not run in Server Components.
- **SplitText (new API)** [types: split-text.d.ts]: `SplitText.create(el, { type: 'lines,words,chars', mask: 'lines', autoSplit: true, aria: 'auto', onSplit: (s) => gsap.from(s.lines, {...}) })`.
  - With `autoSplit`, **return the animation from `onSplit`** so it re-splits and re-plays on resize or font load.
  - `aria: 'auto'` is the default and keeps the text readable to screen readers.

### 3.2 useGSAP [c7: greensock/react]
```tsx
'use client'
const root = useRef<HTMLDivElement>(null)
useGSAP(() => {
  gsap.from('.panel', { yPercent: 20, autoAlpha: 0, stagger: 0.08, scrollTrigger: { trigger: root.current, start: 'top 80%' } })
}, { scope: root, dependencies: [], revertOnUpdate: false })
const { contextSafe } = useGSAP({ scope: root })
const onClick = contextSafe(() => gsap.to('.door', { rotationY: -80 }))   // handlers MUST be wrapped
```
`useGSAP` reverts everything on cleanup. That is exactly what Activity hide/show needs (§1.2).

### 3.3 Lenis + GSAP ticker + ScrollTrigger [c7: lenis/react README; src: lenis-react.d.ts; types]
- `lenis/react` exports `ReactLenis` (also as `Lenis` and default), `useLenis(cb?, deps?, priority?)` and `LenisRef`.
- **The `autoRaf` prop is deprecated: use `options.autoRaf`.**
- `respectReducedMotion` **defaults to true** in 1.3.27. Under reduced motion it forces `lerp: 1` and makes programmatic scrolls instant. Other options: `anchors: true` (anchor links), `allowNestedScroll`, `autoToggle`, `stopInertiaOnNavigate`.
- Import the CSS once: `import 'lenis/dist/lenis.css'`.

```tsx
'use client'
import { ReactLenis, useLenis, type LenisRef } from 'lenis/react'
export function SmoothScroll({ children }: { children: React.ReactNode }) {
  const ref = useRef<LenisRef>(null)
  useEffect(() => {
    const update = (t: number) => ref.current?.lenis?.raf(t * 1000)   // GSAP time is seconds
    gsap.ticker.add(update)
    gsap.ticker.lagSmoothing(0)
    return () => gsap.ticker.remove(update)
  }, [])
  useLenis(ScrollTrigger.update)                                      // keep ScrollTrigger in sync
  return <ReactLenis root options={{ autoRaf: false, anchors: true, lerp: 0.1 }} ref={ref}>{children}</ReactLenis>
}
```
- Mount it once in the root layout. Do not use GSAP ScrollSmoother at the same time (two smooth scrollers fight).
- After fonts or images load: `document.fonts.ready.then(() => ScrollTrigger.refresh())`.

## 4. motion 14.4 (framer-motion 14.4) [src + types]
- Client import: **`import { motion, AnimatePresence, LayoutGroup, MotionConfig, useReducedMotion, useScroll, useSpring, useInView, LazyMotion, domAnimation, m } from 'motion/react'`**.
- `motion/react-client` re-exports `framer-motion/client`. Use `import * as motion from 'motion/react-client'` to render `motion.div` from a **Server Component** file.
- Bundle diet: `LazyMotion features={domAnimation}` plus `m.div` (`motion/react-m`).
- **New in 14:** `AnimateView` (from `motion/react`, via `framer-motion/animate-view`). It does enter/exit/shared view transitions and **requires React/React DOM ≥ 19.3**, which we have. Treat it as new: prototype it before you rely on it.

```tsx
<MotionConfig reducedMotion="user">
  <AnimatePresence mode="wait">
    {open && <motion.div key="drawer" layoutId="cart-panel"
      initial={{ opacity: 0, y: 12 }} animate={{ opacity: 1, y: 0 }} exit={{ opacity: 0, y: 12 }}
      transition={{ type: 'spring', bounce: 0.25, visualDuration: 0.3 }} />}
  </AnimatePresence>
</MotionConfig>
```
- `AnimatePresence` children need stable unique `key`s. `layoutId` animates between elements that share the id. Wrap siblings in `<LayoutGroup>` when they live in different subtrees.
- Division of labour: **motion** for UI micro-interactions (cart, toasts, drawers, layoutId). **GSAP** for scroll storytelling and SVG/text. Never animate the same property with both.

## 5. R3F 9.8 + drei 10.7 (React 19.3) [c7: v9 migration + scaling-performance; types]
- v9 is the React 19 release. **`MeshProps` and the other hardcoded JSX prop types are gone: use `ThreeElements['mesh']`.**
- Remember the peer range `react <19.4`.

```tsx
'use client'
import { Canvas, type ThreeElements } from '@react-three/fiber'
import { PerformanceMonitor, AdaptiveDpr, MeshTransmissionMaterial } from '@react-three/drei'

export default function DoorScene() {
  const [dpr, setDpr] = useState(1.25)
  return (
    <Canvas frameloop="demand" dpr={[1, dpr]} gl={{ antialias: false, powerPreference: 'high-performance' }}
            camera={{ position: [0, 0, 5], fov: 35 }}>
      <PerformanceMonitor onDecline={() => setDpr(1)} onIncline={() => setDpr(1.5)} />
      <AdaptiveDpr pixelated />
      {/* scene */}
    </Canvas>)
}
```
- **`frameloop="demand"`** renders only on prop changes or `invalidate()`. When GSAP drives the scene, call `invalidate()` from the R3F store in the tween's `onUpdate`, or flip it to `'always'` only while the hero is in view.
- **DPR cap:** `dpr={[1, 1.5]}` on mobile and never above 2. Turn `antialias` off and enable it only if needed.
- **Lazy-load** with `next/dynamic({ ssr: false })` from a client file (§1.9). Mount only after first paint and an IntersectionObserver hit, with a **poster image as LCP**. Skip it entirely under `prefers-reduced-motion` or `navigator.deviceMemory <= 4` (the latter is a Chromium-only hint).
- **useScroll/ScrollControls vs GSAP:** drei `ScrollControls` creates **its own scroll container**, which fights Lenis and ScrollTrigger and breaks native page scroll. **Do not use ScrollControls on this site.** Drive the camera or door from a GSAP ScrollTrigger (`scrub`) that writes to refs or a zustand store, and call `invalidate()`.
- **MeshTransmissionMaterial** does an extra scene render per frame (×`samples`) at `resolution`. On mid-range Android use `samples={2..4}`, `resolution={256..512}`, `backside={false}`, or fake it with `MeshPhysicalMaterial` + an envMap. It does not suit an always-running loop.
- Also: share geometries and materials, use `useGLTF.preload`, Draco/meshopt-compressed GLB, KTX2 textures, `<Bvh>` for raycasts, and `<Preload all />` sparingly.
- Remember Activity (§1.2): verify the canvas is disposed or paused when its route is hidden.

### 7.2 Clients [types; c7: supabase/ssr]
- **API change in @supabase/ssr ≥0.10:** `setAll(cookiesToSet, headers)` receives a **second `headers` arg**: `Cache-Control: private, no-store`… Forward those headers on proxy responses so CDNs never cache a session.

```ts
// src/proxy.ts  (matcher limited to admin/auth). Pattern from Supabase docs, adapted for 0.12 headers arg
export async function proxy(request: NextRequest) {
  let res = NextResponse.next({ request })
  const supabase = createServerClient(URL, PUBLISHABLE, { cookies: {
    getAll: () => request.cookies.getAll(),
    setAll(toSet, headers) {
      toSet.forEach(({ name, value }) => request.cookies.set(name, value))
      res = NextResponse.next({ request })
      toSet.forEach(({ name, value, options }) => res.cookies.set(name, value, options))
      Object.entries(headers).forEach(([k, v]) => res.headers.set(k, v))
    } } })
  const { data } = await supabase.auth.getClaims()          // nothing between create and this call
  if (!data?.claims && request.nextUrl.pathname.startsWith('/admin')) {
    return NextResponse.redirect(new URL('/admin/login', request.url))
  }
  return res                                                 // return THIS object (cookies)
}
export const config = { matcher: ['/admin/:path*', '/auth/:path*'] }
```

### 7.4 RLS pattern (SQL for `supabase/migrations/0001_init.sql`)
```sql
-- owners
create table public.admins (user_id uuid primary key references auth.users on delete cascade, created_at timestamptz default now());
alter table public.admins enable row level security;
create or replace function public.is_admin() returns boolean
  language sql stable security definer set search_path = '' as $$
  select exists (select 1 from public.admins a where a.user_id = (select auth.uid()));
$$;
create policy "admins read self" on public.admins for select to authenticated using (user_id = (select auth.uid()));

-- catalogue: public read, owner write
alter table public.products enable row level security;
create policy "public read published" on public.products for select to anon, authenticated using (is_published);
create policy "owner all" on public.products for all to authenticated using (public.is_admin()) with check (public.is_admin());

-- leads/events: anon may INSERT only (no select/update/delete); owner reads
alter table public.leads enable row level security;
create policy "anon insert lead" on public.leads for insert to anon, authenticated
  with check (char_length(name) between 1 and 80 and char_length(coalesce(note,'')) <= 2000);
create policy "owner read leads" on public.leads for select to authenticated using (public.is_admin());
```
- With insert-only RLS, call `.insert(row)` **without `.select()`**. A returning select needs a SELECT policy and fails for anon.
- Our contract routes inserts through `/api/lead`. The **preferred** path is a server insert with `supabaseAdmin()` after zod, honeypot and throttle, with **no anon insert policy at all** (less spam surface). Keep the anon policy only if the client writes directly.
- Wrap `auth.uid()` as `(select auth.uid())` in policies. It is a known RLS performance pattern (initplan caching).

### 7.5 Storage: custom-upload bucket [c7: storage access-control; types]
```sql
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('custom-uploads', 'custom-uploads', false, 10485760, array['image/png','image/jpeg','image/webp','image/svg+xml','application/pdf']),
       ('product-images', 'product-images', true, 5242880, array['image/avif','image/webp','image/jpeg','image/png']);
-- insert-only for visitors, into one folder; no select → they cannot list or read others' files
create policy "visitor upload" on storage.objects for insert to anon, authenticated
  with check (bucket_id = 'custom-uploads' and (storage.foldername(name))[1] = 'incoming');
```
