# As-built API reference (binding for section/page builders)

## Data & logic (F2)
- `@/lib/types` — CONTRACTS §3 + `Product.updatedAt`; `CartItem.variantAttrs?: Record<string,string>` (pass `variant.attrs` when adding so bookmark plain/magnetic bundles match); `HoodieTier {id, level, code, name, gsmMin, gsmMax, gsmLabel, price, feel}`; `TeeFit {id:'oversized'|'regular'|'baby', label, price, blurb}`; `ApparelCustomRules {companyDesignFee, halfHalfFee, zones:{front,back:{w,h,unit}}, note}`; `ProductFilter {collection?, type?: ProductType|ProductType[], q?, min?, max?, featured?}`; `CustomQuote {type, quantity, minQty, meetsMinimum, unitPrice:number|null, extras:{label,amount,per:'piece'|'order'}[], total:number|null, estimate, notes:string[]}`.
- `@/lib/data/seed` — `collections products events partnerships settings instaPosts([]) APPAREL_SIZES bundleRules customRules apparelCustom hoodieTiers teeFits`. **Client code imports rules from `@/lib/data/rules`** (not the whole catalogue). 65 products; dropOfWeek = `cursed-static-oversized-t-shirt`; 8 featured.
- `@/lib/data/repo` (server-only, `'use cache'`, never throws): `getCollections() getCollection(slug) getProducts(filter?) getProduct(slug) getDropOfWeek() getRelatedProducts(slug, limit=4) getEvents() getPartnerships() getSettings() getInstaPosts() getBundleRules() getCustomRules() getHoodieTiers() getTeeFits()`, `TAGS` (admin calls `updateTag(TAGS.x)` after writes).
- `@/lib/pricing` (pure): `formatINR(n)` "₹1,200" · `formatINRRange(lo,hi)` "₹1,200–2,000" · `parseRange(s)` · `variantBounds(v)` · `variantPriceLabel(v)` · `productPriceLabel(p)` ("₹800" / "From ₹400" / "₹1,200–2,000" / "Price on request") · `ruleMatches(rule,item)` · `computeTotals(items, rules?) → CartTotals` (applied, hints, per-line saving) · `minQtyFor(type)` · `customQuote(spec:{product,quantity,mode,halfHalf}, product?, variantId?) → CustomQuote`. Tests: `node --test src/lib/pricing.test.ts`.
- `@/lib/cart` (client): `useCart() → { items, open, lastAdded:{key,name,image,qty,nonce,at}|null, add(AddInput), remove(key), setQty(key,q), clear(), setOpen(b), clearLastAdded() }` (`AddInput = Omit<CartItem,'key'|'qty'> & {key?, qty?}`; same product+variant+size merge; qty cap 99) · `useWishlist() → { ids, toggle(id), has(id), clear() }` · `useHydrated()` (gate counts on it) · `ensureHydrated()` · `useCartCount()` · `lineKey(item)`.
- `@/lib/whatsapp`: `buildOrderMessage({items, totals?, name?, city?, note?, customLinks?, ref?, orderRef?}) → string` · `waLink(text, number?)` · `whatsappNumber(fromSettings?)` — number comes from Admin → Settings (`settings.whatsapp`): server `whatsappNumber((await getSettings()).whatsapp)`, client `useWhatsappNumber()` from `@/components/SiteSettingsProvider` (also re-exported by `@/components/Providers`); env var is fallback only.
- `@/lib/analytics` (client, never throws, off under DNT/GPC/webdriver): `track(event, props?)` · `initAnalytics()` · `trackPageView(path?)` · `flush(beacon?)` · `getAttribution()` · `captureAttribution()` · `getVisitorId()` · `getSessionId()` · `isTrackingEnabled()`.
- `@/lib/leads`: `submitLead(input: LeadInput, opts?: {honeypot?, signal?}) → Promise<{ok, id?, stored, error?: 'invalid'|'rate-limited'|'network'|'server'|…, fieldErrors?}>`. `remind_me`/`newsletter` REQUIRE `contact` (phone or email).
- `@/lib/supabase/client` `supabaseBrowser()` · `/server` `supabaseServer()`, `publicClient()`, `getAdminSession() → {userId,email,isAdmin}|null` · `/admin` `supabaseAdmin()` · `/env` `isSupabaseConfigured()`, `isSupabaseAdminConfigured()`. All return `null` when unconfigured.
- `@/lib/seo`: `SITE_URL PRODUCTION_URL SITE_NAME INSTAGRAM_URL ORG_ID WEBSITE_ID DISCLAIMER` · `absUrl(path)` · `orgJsonLd(full?)` · `websiteJsonLd()` · `productJsonLd(p,{collectionName?})` (ProductGroup for apparel) · `breadcrumbJsonLd([{name,path}])` · `eventJsonLd(e)` (null unless confirmed+dated) · `faqJsonLd([{q,a}])` · `itemListJsonLd(products,{limit?,name?})` · `collectionPageJsonLd(name,path,products,description?)` · `serviceJsonLd({name,serviceType,path,description?})`.
- `@/components/seo/JsonLd`: `<JsonLd data={obj | (obj|null)[] | null} id? />`.
- HTTP: `POST /api/lead` · `POST /api/upload-url` body `{filename, contentType, size}` → `{bucket, path, token, signedUrl, maxBytes}` then `supabaseBrowser().storage.from(bucket).uploadToSignedUrl(path, token, file)`; body `{viewPath}` → `{url}` (7-day signed read); 503 `{error:'uploads-unconfigured'}` when Supabase missing · `POST /.netlify/functions/track` (204).

## Shell, motion & FX (F1)
- `@/lib/motion`: `EASE {out,punch,slam,inOut,in,hover}` · `CSS_EASE` (+ CSS vars `--ease-expo|punch|slam|inout|exit|hover`) · `SPRING` · `DUR {ui,enter,slam}` · `registerGsap()` (useGSAP, ScrollTrigger, SplitText, DrawSVGPlugin, Flip, CustomEase; eases `'ted-slam'`, `'ted-ink'`) · hooks `useReducedMotion() useIsTouch() useFinePointer() useIsClient() useLowPower()` · `isLowPower() prefersReducedMotion()`.
